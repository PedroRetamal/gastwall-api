# Gastwall API

Gastwall es una API RESTful para la gestión de finanzas personales. Permite a los usuarios registrar sus ingresos y gastos, crear categorías personalizadas y visualizar su estado financiero de forma simple y segura.

## Tecnologías
- **Backend:** Python, FastAPI
- **Base de Datos:** PostgreSQL, SQLAlchemy
- **Seguridad:** JWT (JSON Web Tokens), Bcrypt
- **Testing:** PyTest
- **Infraestructura:** Docker, Docker Compose

## Características del MVP
- Registro e inicio de sesión de usuarios.
- CRUD de categorías de ingresos y gastos.
- Registro de transacciones (con fecha, monto, descripción y categoría).
- Dashboard con el saldo total y transacciones recientes.
